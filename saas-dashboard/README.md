# Base SaaS Dashboard

A responsive React dashboard built with Vite and the supplied design assets in `public/Saas`.

## Run locally

```bash
npm install
npm run dev
```

## Validation

```bash
npm run lint
npm run build
```

## Sections

- Dashboard overview and recent orders
- Product analytics and customer list
- Invoice management
- Schedule management and calendar views
- Task board, list, and timeline
- Messaging, notifications, profile, and settings
- Login and sign-up demo screens

Interactive data is held in browser memory, with notification preferences persisted in local storage. Authentication and social sign-in are presentation-only and are not connected to a backend.
